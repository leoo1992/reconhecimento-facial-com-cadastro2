# Face Recognition with Registration — Version 2

A study web application for registering and managing people with facial recognition-related features. The backend uses Express and MySQL persistence through Sequelize.

## Stack
- Node.js and Express
- MySQL and Sequelize
- JavaScript
- Jade templates

## Run
Configure the MySQL connection in the environment, install dependencies, and start the server:

```bash
npm install
npm start
```

The `start` script runs `node ./bin/www`.
