# Reconhecimento facial com cadastro — versão 2

Aplicação web de estudo para cadastro e gerenciamento de pessoas com funcionalidades relacionadas a reconhecimento facial. O backend utiliza Express e persistência MySQL por Sequelize.

## Stack
- Node.js e Express
- MySQL e Sequelize
- JavaScript
- Jade templates

## Como executar
Configure a conexão com MySQL no ambiente, instale as dependências e inicie o servidor:

```bash
npm install
npm start
```

O script `start` executa `node ./bin/www`.
